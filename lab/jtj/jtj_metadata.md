# Just The Job (JTJ) — Metadata (Data Dictionary) for Key Data Elements

This document provides detailed metadata entries for selected data elements used in JTJ's data flows and data stores.

---

## 1. `customer_number`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Customer ID, Customer No., Cust. No.                    |
| **Description**     | Unique identifier allocated to each customer for tracking and marketing purposes |
| **Composition**     | Atomic — single alphanumeric value                       |
| **Data Type**       | VARCHAR(10)                                             |
| **Length / Format**  | "C" + 5-digit zero-padded number (e.g. C00042)          |
| **Domain / Range**  | C00001 to C99999                                        |
| **Constraints**     | PRIMARY KEY; NOT NULL; UNIQUE; auto-allocated on registration |
| **Source**           | Generated by system when customer is first registered (Process 3.0) |
| **Example**         | `C00042`                                                |

---

## 2. `booking_number`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Booking Ref, Job Reference, Booking ID                   |
| **Description**     | Unique reference number assigned to each cleaning booking |
| **Composition**     | Atomic — single alphanumeric value                       |
| **Data Type**       | VARCHAR(10)                                             |
| **Length / Format**  | "B" + 5-digit zero-padded number (e.g. B00156)          |
| **Domain / Range**  | B00001 to B99999                                        |
| **Constraints**     | PRIMARY KEY; NOT NULL; UNIQUE                            |
| **Source**           | Generated when booking form is created (Process 3.0)     |
| **Example**         | `B00156`                                                |

---

## 3. `agreed_price`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Job Price, Quoted Price, Cleaning Cost                   |
| **Description**     | The price agreed between the office manager and customer for a one-off cleaning job |
| **Composition**     | Atomic — single numeric value                            |
| **Data Type**       | DECIMAL(8, 2)                                           |
| **Length / Format**  | Pounds and pence, 2 decimal places (e.g. 250.00)        |
| **Domain / Range**  | 0.01 to 99999.99                                        |
| **Constraints**     | NOT NULL for one-off jobs; must be > 0                   |
| **Source**           | Estimated by office manager during property visit (Process 2.0) |
| **Example**         | `350.00`                                                |

---

## 4. `hourly_rate`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Rate, Cleaning Rate, Hourly Charge                       |
| **Description**     | Negotiated hourly rate for regular weekly cleaning jobs   |
| **Composition**     | Atomic — single numeric value                            |
| **Data Type**       | DECIMAL(6, 2)                                           |
| **Length / Format**  | Pounds per hour, 2 decimal places (e.g. 15.50)          |
| **Domain / Range**  | 5.00 to 100.00                                          |
| **Constraints**     | NOT NULL for regular jobs; must be ≥ minimum wage        |
| **Source**           | Negotiated between office manager and customer (Process 2.0) |
| **Example**         | `15.50`                                                 |

---

## 5. `job_type`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Service Type, Cleaning Type                              |
| **Description**     | Indicates whether the job is a one-time clean or recurring weekly service |
| **Composition**     | Atomic — single enumerated string                        |
| **Data Type**       | VARCHAR(10)                                             |
| **Length / Format**  | Fixed values                                            |
| **Domain / Range**  | { "ONE-OFF", "REGULAR" }                                |
| **Constraints**     | NOT NULL; must be one of the two allowed values          |
| **Source**           | Determined at time of booking (Process 3.0)              |
| **Example**         | `"REGULAR"`                                             |

---

## 6. `invoice_number`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Invoice No., Invoice Ref, Invoice ID                     |
| **Description**     | Unique reference number for each generated invoice       |
| **Composition**     | Atomic — single alphanumeric value                       |
| **Data Type**       | VARCHAR(10)                                             |
| **Length / Format**  | "INV" + 5-digit zero-padded number (e.g. INV00089)      |
| **Domain / Range**  | INV00001 to INV99999                                    |
| **Constraints**     | PRIMARY KEY; NOT NULL; UNIQUE; auto-generated            |
| **Source**           | Generated when invoice is created (Process 7.0)          |
| **Example**         | `INV00089`                                              |

---

## 7. `cleaner_id`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Cleaner Number, Staff ID, Employee ID                    |
| **Description**     | Unique identifier for each cleaner on JTJ's staff        |
| **Composition**     | Atomic — single alphanumeric value                       |
| **Data Type**       | VARCHAR(10)                                             |
| **Length / Format**  | "CL" + 4-digit zero-padded number (e.g. CL0012)         |
| **Domain / Range**  | CL0001 to CL9999                                        |
| **Constraints**     | PRIMARY KEY; NOT NULL; UNIQUE                            |
| **Source**           | Allocated when cleaner is registered in Cleaner File     |
| **Example**         | `CL0012`                                                |

---

## 8. `status`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Job Status, Booking Status, Invoice Status               |
| **Description**     | Current status of a booking or invoice in the system     |
| **Composition**     | Atomic — single enumerated string                        |
| **Data Type**       | VARCHAR(15)                                             |
| **Length / Format**  | Fixed values                                            |
| **Domain / Range**  | Booking: { "BOOKED", "COMPLETED", "INVOICED", "PAID" }; Invoice: { "UNPAID", "PAID" } |
| **Constraints**     | NOT NULL; must transition in valid order (BOOKED → COMPLETED → INVOICED → PAID) |
| **Source**           | Updated by relevant processes (3.0, 6.0, 7.0, 8.0)     |
| **Example**         | `"COMPLETED"`                                           |

---

## 9. `hours_worked`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Hours, Work Hours, Time Worked                           |
| **Description**     | Number of hours a cleaner worked on a specific job       |
| **Composition**     | Atomic — single numeric value                            |
| **Data Type**       | DECIMAL(4, 1)                                           |
| **Length / Format**  | Hours with half-hour precision (e.g. 3.5)               |
| **Domain / Range**  | 0.5 to 24.0                                             |
| **Constraints**     | NOT NULL; must be > 0; typically 1–8 hours per job       |
| **Source**           | Recorded after cleaning job completion (Process 5.0)     |
| **Example**         | `4.5`                                                   |

---

## 10. `property_address`

| Attribute           | Value                                                   |
|---------------------|---------------------------------------------------------|
| **Alias**           | Cleaning Address, Job Address, Site Address               |
| **Description**     | Full postal address of the property to be cleaned        |
| **Composition**     | Composite: house_number + street + city + postcode       |
| **Data Type**       | VARCHAR(200)                                            |
| **Length / Format**  | Standard UK postal address format                        |
| **Domain / Range**  | Any valid UK address                                     |
| **Constraints**     | NOT NULL                                                |
| **Source**           | Provided by customer at booking (Process 1.0/3.0)        |
| **Example**         | `"14 Oak Lane, Sheffield, S10 2DN"`                      |
